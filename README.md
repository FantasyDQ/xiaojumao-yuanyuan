## 这是什么

缘缘是一个常驻 Windows 桌面的 AI 助手，形象是一只小橘猫。

与「每次打开都从零开始」的聊天工具不同，它强调两件事：一是**记得住**——你说过的每一句话都会被妥善留存；二是**做得了**——能够独立处理复杂任务，并在危险操作前保留人工确认。所有数据均保存在本机。

## 核心特点

### 1. 长久记忆——聊过的每一句话，都找得回

四层记忆，各管一件事：

| 层       | 作用                   | 机制                                                         |
| -------- | ---------------------- | ------------------------------------------------------------ |
| 工作记忆 | 当前对话上下文         | 保留最近 20 轮，环形                                          |
| 对话摘要 | 超出 20 轮后延续上下文 | 触发压缩，结果持久化，跨会话保留                               |
| 情景记忆 | 找回过去说过的话       | `history.db`(sql.js / WASM SQLite)：原文表永久保留，摘要表作检索索引 |
| 用户画像 | 记住你是谁             | 增量提取，上限 30 条，可查看 / 添加 / 编辑 / 删除 / 清空       |

**索引与负载分离**：同一段对话，原文注入约 17,242 token，摘要索引只需约 86 token。平时只带索引，需要时再按 id 展开原文，既不丢信息，也不撑爆上下文。

**对话不丢，有多重保障**：

- 原文单独存表，永久保留，摘要只是索引。
- 退出前同步补写原文并 flush。
- 记忆提取失败时，退化为用原话写入索引。
- 画像只提取新增事实与被取代的旧事实，更精确的新事实会替换旧事实。
- 敏感信息(密码、密钥、证件号、银行卡号)不进画像。
- 注入有 2000 字符预算，快照每 5 分钟刷新一次以保住前缀缓存；短噪声消息会被过滤。
- 邮件联系人可从邮件正文自动记忆，也可以查看和删除。

> **技术细节**：对话原文永久保存在本机历史库，可按关键词检索、按 id 调出。

### 2. 能动手，但有边界

- **多步工具循环**：模型自主连续调用工具直到完成；有循环上限保护；单步失败不中断整体；全程记录操作日志。
- **25 项内置工具**：任务编排、文件系统、知识检索、代码执行、系统控制、时间与通信。
- **人机协作边界**：
  - 复杂任务先列计划，等你确认
  - 参数缺失或有歧义时，弹选项让你选
  - 删除等不可逆操作二次确认
  - 定时任务执行前展示脚本与目标
  - 简单的单步任务直接执行，不打扰你
- **代码执行有两层护栏**：执行前正则扫描高风险操作(删除、格式化、改注册表、关机、提权、杀进程等)，命中后需人工确认。

### 3. 做成功的事，可以沉淀成技能

技能是带结构化指令的 `SKILL.md`，解析后注入系统提示词，相似任务自动激活。

**自改进闭环**：一次含工具调用、且未中断的 Agent 执行结束后，可一键把「请求 + 操作日志 + 回复」连同现有技能清单交给模型，生成新的 `SKILL.md` 入库。

技能可从技能商店检索安装，也可手动添加或用 ZIP 导入。内置技能随包分发，启动时校验更新。

### 4. 数据全在本地

聊天记录、用户画像、历史库、定时任务、技能库、MCP / IMA / 邮箱配置，全部存在本机。只有你自己配置的模型、搜索、TTS 等接口会收到请求内容。

## 功能一览

| 模块             | 能力                                                         |
| ---------------- | ------------------------------------------------------------ |
| **对话与推理**   | OpenAI 兼容接口，SSE 流式输出；轻量 / 主模型双路由；思考模式(off / auto / on × low / medium / high)；意图路由；问答出 Markdown，报告 / 方案 / 仪表盘自动出交互式 HTML |
| **代码执行**     | Python / PowerShell；内置 Python 运行时；依赖缺失自动 pip 安装；输出超长自动截断 |
| **文件与文档**   | 读取 txt / md / json / csv / PDF / docx / xlsx 等；复制 / 移动 / 删除 / 定位；全盘模糊搜索；粘贴与拖拽附件；产出可导出为 Word / Excel / PPT 格式 |
| **联网与资讯**   | Tavily 搜索；网页抓取三级降级；天气；IMA 知识库对接             |
| **邮件**         | 发送(HTML / 纯文本)、读取收件箱、联系人自动记忆              |
| **语音与多模态** | 流式 TTS(首块约 700ms 开播)、ASR、独立视觉模型识图           |
| **会议纪要**     | 录音 → 转写 → 流式生成纪要；长会议分段录制后合并；可存文件、可上传 IMA |
| **定时与自动化** | 定时任务(脚本模式 + AI 模式，脚本失败转 AI)；循环提醒；带截止时间的待办与重复提醒；中文时间解析(「X 分钟后」「下午 3 点」) |
| **MCP 外接**     | Streamable HTTP + SSE 双支持，自动探测与切换；可直接导入 Claude MCP JSON 配置；自动发现并合并外部工具 |
| **桌面形态**     | 小橘猫形象，有自主走位与情绪动作；置顶可控、全屏自动让路、鼠标穿透、托盘常驻、开机自启 |

## 🚀 快速安装

**Windows 开发运行：**

```powershell
npm install        # 安装依赖
npm start          # 启动应用（npm run dev 带 --dev 参数）
```

**打包分发（NSIS 安装包 / 免安装版）：**

```powershell
npm run dist           # 同时产出 NSIS + portable
npm run dist:nsis      # 仅安装包
npm run dist:portable  # 仅免安装版（小橘猫缘缘-免安装版-x.y.z.exe）
npm run icon           # 重新生成多尺寸 ICO
```

**首次使用：** 复制 `config.example.json` 为 `config.json`，填入自己的模型 / TTS / 视觉 / 搜索 API Key 即可（该文件含密钥，请勿提交到公开仓库）。

> **TTS / ASR 接口（可选）**：默认与主模型共用 `llm_api_base` / `llm_api_key`；如需接入其他服务商，在 `config.json` 中填入 `tts_api_base` / `tts_api_key`、`asr_api_base` / `asr_api_key` 即可，留空则自动跟随主模型。

## 📁 项目结构

```text
xiaojumao-yuanyuan/
├── main.js                # 主进程能力层（~9300 行）：Agent 循环、工具执行器、
│                          #   意图路由、记忆系统、技能/MCP/邮件/天气/TTS/ASR、
│                          #   窗口与托盘、全部 IPC handler
├── preload.js             # contextBridge 安全暴露 window.pet API（IPC 受控通道）
├── history-db.js          # 情景记忆：sql.js(WASM SQLite) 摘要索引表 + 原文表
├── config.example.json    # 配置模板：复制为 config.json 后填入自己的 Key
├── src/                   # 渲染进程展示层
│   ├── index.html         # 窗口结构（~800 行）
│   ├── css/main.css       # 橘猫主题样式（~2400 行）
│   └── js/
│       ├── renderer.js    # 入口：装配各模块
│       ├── state.js       # 共享状态
│       ├── chat.js        # 对话 UI、流式渲染、附件、沉淀按钮（核心）
│       ├── markdown.js    # Markdown 渲染 + 代码块/文档块复制
│       ├── pet.js         # 宠物形象与情绪动作
│       ├── movement.js    # 走位（静止是默认态）
│       ├── interaction.js # 交互（点击、拖拽、对话气泡）
│       ├── care.js        # 照护状态
│       ├── avatar.js      # 自定义头像
│       ├── settings.js    # 设置面板
│       ├── skills.js      # 技能浏览 / 安装
│       ├── mcp.js         # MCP Server 管理
│       ├── todo.js / reminders.js / scheduled.js   # 待办 / 提醒 / 定时任务
│       ├── meeting.js     # 会议纪要
│       ├── weather.js / city-codes.js  # 天气与城市名映射
│       ├── fileops.js     # 文件操作（复制/移动/删除/定位）
│       ├── ima.js         # IMA 知识库
│       └── whoami.js      # 用户画像展示
├── python/                # 内置 Python 3.11 运行时（run_code 用，随包分发）
├── build/                 # icon.ico / icon.png 应用图标
├── config-build/          # 配置打包工具（独立小应用）
├── CAPABILITIES.md        # 能力规格：所有功能与实现机制（可逐条回溯到源码）
├── DESIGN.md              # 设计哲学：三条原则、记忆分层、生命感、工程纪律
└── main_js_index.md       # main.js 完整定义索引（函数 / 常量 / IPC / 工具清单）
```

**分层约定**：`main.js` 是能力层（LLM、工具、记忆、系统操作全在这里），`src/` 是纯展示层，两者只经 `preload.js` 暴露的 `window.pet` IPC 通道通信。改能力去 `main.js`，改表现去 `src/`，一份逻辑不要写两遍。
